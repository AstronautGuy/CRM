# Micro Commits

The user has explicitly requested to do **micro commits** for each change made across this project.

## Instructions
- Commit frequently. 
- Break down larger tasks into logical chunks and commit each chunk separately with a descriptive message.
- A single feature or fix might involve several micro-commits (e.g., one for UI changes, one for API additions, one for schema updates).
- Make sure to add this step to your execution process for every task.
