# Phase 1 Plan 3: Super Admin Subscription Management & Org Portal

## Objective
Build tRPC procedures and Super Admin dashboard views to manage client organizations, subscription plans, pricing, feature gating, and payment tracking.

## Tasks
- [ ] Build `src/server/api/routers/admin.ts` tRPC router with procedures for:
  - Managing subscription plans (create, edit pricing, list).
  - Managing organizations (list, assign subscription plan, toggle active status).
  - Recording subscription payments & tracking renewal dates.
- [ ] Build tRPC middleware in `src/server/api/trpc.ts` for:
  - `protectedProcedure`: Requires authenticated user.
  - `superAdminProcedure`: Requires Super Admin user role.
  - `tenantProcedure`: Enforces active tenant organization context.
- [ ] Create Super Admin dashboard page at `src/app/admin/plans/page.tsx` & `src/app/admin/organizations/page.tsx`.
- [ ] Implement login & registration authentication UI pages at `src/app/(auth)/login/page.tsx` and `src/app/(auth)/register/page.tsx`.

## Verification
- Run `pnpm typecheck` to ensure all tRPC procedures, page routes, and middleware compile without type errors.
