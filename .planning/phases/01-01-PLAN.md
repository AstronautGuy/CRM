# Phase 1 Plan 1: Database Schema & Authentication Infrastructure

## Objective
Configure database schema for users, accounts, sessions, organizations, members, subscription plans, and subscriptions using Drizzle ORM. Setup NextAuth.js with Drizzle Adapter and credentials/OAuth support.

## Tasks
- [ ] Install `@auth/drizzle-adapter`, `next-auth@beta`, `bcryptjs`, `@types/bcryptjs`.
- [ ] Extend `src/server/db/schema.ts` with NextAuth tables (`users`, `accounts`, `sessions`, `verificationTokens`) and Multi-Tenancy / Subscription tables (`organizations`, `organization_members`, `subscription_plans`, `subscriptions`).
- [ ] Setup Auth configuration in `src/server/auth.ts` supporting Credentials (Email & Phone) and Social OAuth (GitHub / Google).
- [ ] Export NextAuth handler in `src/app/api/auth/[...nextauth]/route.ts`.
- [ ] Add `auth` session helper to tRPC context in `src/server/api/trpc.ts`.

## Verification
- Run `pnpm db:push` or `pnpm typecheck` to verify schema compilation and type consistency.
