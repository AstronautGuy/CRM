# Tech Stack

## Core Technologies
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript 5.8
- **Runtime**: Node.js
- **Package Manager**: pnpm 11.5.1

## Data Layer & API
- **ORM**: Drizzle ORM v0.41
- **Database**: PostgreSQL (driver: `postgres` v3.4)
- **API Framework**: tRPC v11 with React Query v5
- **Validation**: Zod v3.24
- **Environment Management**: `@t3-oss/env-nextjs`

## Frontend & Styling
- **React**: React 19 / React DOM 19
- **Styling**: TailwindCSS v4 with PostCSS
- **Serialization**: SuperJSON v2.2

## Tooling & Quality
- **Linter & Formatter**: Biome v2.2 (`biome.jsonc`)
- **Database Tooling**: Drizzle Kit v0.30 (`drizzle.config.ts`)
- **Type Checking**: TypeScript (`tsconfig.json`)
